# Sources

What this design system is built from.

1. The first design brief of 2026-10-18. Source of the palette, type, wordmark, cover pattern, hero copy and the action. All values are `new`.
2. The project facts: what the tool is, its surfaces, and that no logo, landing page or brand existed before this system.
3. `README.md` of the repository. Source of the one-line purpose: the tool turns a design system into Apple Terminal.app themes and checks them with readability gates.
4. `AGENTS.md`. Source of the rules: no Terminal.app changes, Python 3.9 standard library only, no private tokens in the system.
5. The voice examples in `README.md` of this folder come from the project goal statement, quoted without edits.

Not used: the test fixtures, measurement outputs, and any environment or credentials file.
