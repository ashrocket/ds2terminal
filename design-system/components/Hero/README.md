The landing hero for ds-terminal-theme: the name, one line of purpose, and one install action.

When to use: the first screen of the project's landing page, or any page that introduces the tool.

What the consumer supplies: nothing for the page. Replace the `href` of the action with the real install link when one exists. The placeholder `#install` is not a live link.

Do: keep the name in `display`, keep the purpose line to one sentence, and keep one action.

Do not: add a second action, add imagery, or change the name's case. Do not add a brand colour other than `ink`, `link-blue` and `ground`.
