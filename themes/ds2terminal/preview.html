Faint (SGR 2) samples use the measured Terminal blend (colorlab.DIM_BLEND, colorlab.DIM_POWER). The two Claude Code samples use the theme tables of Claude Code 2.1.323. The ANSI theme draws the text color on ANSI green and red cells for diff lines. The standard theme uses its own colors on the background of this theme. The report gives the contrast of each pair and the theme to use.

The browser draws this preview; Terminal.app can render text a little differently. Run scripts/demo.py in a Terminal window that uses the theme to see the real colors.
